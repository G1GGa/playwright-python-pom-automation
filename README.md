# 🧪 SauceDemo UI Automation Framework

Automated UI test suite for [SauceDemo](https://www.saucedemo.com) built using **Python**, **Playwright (Sync API)**, and the **Page Object Model (POM)** architectural design pattern.

---

## 🛠️ Tech Stack

* **Language:** Python
* **Test Automation Tool:** Playwright (Sync API)
* **Design Pattern:** Page Object Model (POM)
* **Target Application:** SauceDemo (E-commerce testing ground)
